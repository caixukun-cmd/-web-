📘 平台 API 说明面板

`car` 控制接口
负责运动控制、转向、循线与轨道加载。
car.forward(speed, duration) car.backward(speed, duration) await car.load_demo_track() await car.enable_line_following(...)
`env` 环境状态
读取当前小车与环境状态，适合写闭环控制逻辑。
env.get_state() env.is_collision() env.get_collision_count() env.get_progress()
`task` 任务接口
描述当前任务、结束条件与成功条件。
task.get_info() task.is_finished() task.is_success()
`judge` 评测接口
统一获取分数、通过状态和详细评测报告。
judge.get_report() judge.get_score() judge.is_passed()
`vision` 视觉接口
读取图像帧、调用平台检测器、提交用户检测结果。
await vision.get_frame() await vision.detect() vision.submit_result(...) await vision.get_evaluation()
建议上手顺序
先跑示例，再看状态，再做评测。
1. 基本移动演示 2. 自动循线演示 3. 评测接口演示
提示：想快速体验新接口，请在左上角示例代码里选择“评测接口演示”。如果要做算法评测，推荐先调用 `task.get_info()` 了解任务，再结合 `env` 与 `judge` 编写闭环逻辑。
